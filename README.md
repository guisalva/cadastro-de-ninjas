
# API Cadastro de Ninjas

API Rest desenvolvida em JAVA para gerenciamento de ninjas e missões, inspirado no universo de **Naruto**.

O projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento de APIs utilizando Java e **Spring Boot**, incluindo operações CRUD, persistência de dados, relacionamentos entre entidades e boas práticas de desenvolvimento.



## 🎯 Objetivo

O objetivo deste projeto é criar uma API capaz de gerenciar:
- Ninjas
- Missões
- Relação entre ninjas e missões

Além de servir como projeto de estudo para praticar desenvolvimento Back-end com Java.
## 🛠️ Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Database H2
- Flyway
- Thymeleaf (UI simples para visualização)
- Swagger


## 🚀 Instalação

Clone o repositório:
```bash
  git clone https://github.com/guisalva/cadastro-de-ninjas
```

Entre na pasta:
```bash
  cd cadastro-de-ninjas
```

Execute o projeto:
```bash
  mvn spring-boot:run
```
